4. DECISION

  Why: only path with DX12 -> Metal on Apple Silicon. Brew wine 7.7 lacks current D3DMetal. Porting Kit 6.7.0 is fallback only. No VM (heavy, non-native feel).
  Launch Mars.exe for play. MarsDebug.exe only for diagnosed dev runs.

6. LAUNCHER BEHAVIOR
  On start:
    1. Check /Volumes/External mounted and Mars.exe exists. If not, error dialog + log, exit 10.
    2. Check wine binary exists. If not, exit 11.
    3. Ensure prefix exists; if missing, wineboot -u once (with timeout guard).
    4. Rotate logs (keep last 10, gzip older).
    5. Set env (normal mode quiet, debug mode verbose) and exec wine64 Mars.exe, tee all output to log file.
    6. On nonzero exit, append exit code + tail to log and show notification with log path. Never delete the failing log.
  Env normal:
    WINEPREFIX=<prefix> WINEDLLOVERRIDES=steam_api64=n,b MMCS=1
    MTL_HUD_ENABLED=0 WINEDEBUG=+seh,+err,+loaddll
    DXMT / D3DMetal defaults from GPTK (no override unless diagnosed).
  Env debug (--debug):
    WINEDEBUG=+timestamp,+pid,+seh,+err,+loaddll,+d3d12 MTL_DEBUG_LAYER=1 MTL_HUD_ENABLED=1

10. RISKS
  R1 GPTK 3.0-3 on macOS 27.2: newest OS, possible breakage. Mitigation: keep Porting Kit 6.7.0 as fallback, log GPTK version in every run.
  R2 DLSS dll on Apple GPU: may warn or fall back. Mitigation: select XeSS or native in-game; do not delete nvngx_dlss.dll until diagnosed.
  R3 exFAT quirks: no symlinks, slow random reads for 8.8 GB Packs. Mitigation: prefix internal; if stutter, copy game to internal (needs 11 GB, only 27 GB free, tight but possible).
  R4 Old brew wine shadowing PATH: mitigation: launcher uses absolute GPTK wine path, never bare wine64.
  R5 Bink movies (Movies/ 599 MB) black screen: mitigation: test windowed + log for mfplat/wmcodecs errors; add mf install only if log says so.
